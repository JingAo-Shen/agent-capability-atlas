不用再选：先装这一套日常工具箱

一个能执行本地命令的 Agent，配四个工具。覆盖读资料、生成文档、处理音视频和批量改图；普通 Windows 电脑即可起步。

Windows 10 / 11 · x64无需独显无需额外模型 API Key首次安装需联网

这四个工具在所选用法下不另收云端调用费；你使用的 Agent / 模型费用另计。“通用”指本地命令接口，纯聊天客户端若没有本地执行工具，不能直接使用本方案。

01 / 读资料

MarkItDown

让 Agent 读文本型 PDF、Word、PPT 和 Excel，提取内容做摘要。

你说：
读这个文件夹里的资料，列出关键信息和对应文件名。
本方案只安装文档格式依赖；不含扫描件 OCR、语音识别或高保真排版还原。微软项目与安装说明 ↗
02 / 出文档

Pandoc

把 Agent 写好的内容转换成 Word、HTML 或 EPUB。

你说：
把这份总结做成有标题层级、目录和表格的 Word 文件。
基础包不包含 PDF 排版引擎；中文复杂版式仍需要检查。官方安装说明 ↗
03 / 处理音视频

FFmpeg

剪视频、压缩录屏、提取音频、抽帧和合并已有字幕。

你说：
把这段录屏压缩成方便发送的 MP4，保留原文件。
不自动听懂录音，也不自动生成字幕；转写需要另加识别引擎。官方页面及 Windows 构建入口 ↗
04 / 批量改图

ImageMagick

批量缩放、转换格式、拼图和制作图片预览表。

你说：
把这些照片缩到最长边 1600 像素，另存到新文件夹。
用于确定性图片处理；不包含 AI 生图或语义修图模型。官方命令行文档 ↗

网页不会自动安装软件。脚本默认只检测，加 -Install 才补装；安装器可能需要你确认许可或管理员提示。下载失败或依赖出错会停止并显示错误。脚本已做语法与检测模式检查，未在全新电脑上完整安装实测。

想自己操作？在脚本所在文件夹打开 PowerShell
powershell -NoProfile -File .\install-agent-starter.ps1
powershell -NoProfile -File .\install-agent-starter.ps1 -Install

第一行只检测；第二行安装缺项并运行样本检查。若系统阻止运行脚本，把报错交给 Agent 处理，不需要永久修改系统执行策略。安装可能更新用户 PATH；完成后退出并重新打开 Agent。

安装来源：Microsoft WinGet（FFmpeg 为 Gyan Windows 构建）与 uv 隔离工具环境。uv 会按需下载 Python；各组件保留原许可。

什么时候再加东西？

每天有会议录音：再加 faster-whisper；需要选模型、测试速度，首次模型下载不算即装即用。
经常处理扫描件：再加 PaddleOCR，并用自己的扫描样本验收。
确实要配音：再考虑 VoiceStudio，需要下载并选择语音引擎。
做软件逆向：再装 REA + Ghidra，需要额外运行环境和分析流程。

本地大模型、向量库、Docker、n8n 和桌面点击自动化暂不放进默认包。它们对应专门需求，会增加部署和维护工作。浏览器先用 Agent 已有的浏览器能力；只有缺少时，再按客户端接入 Playwright。

选择依据：常见文件任务覆盖面、明确的命令行接口、较低部署负担和可检查输出。这是面向日常使用的编辑判断，不是兼容所有 Agent 的认证套装，也不是对 53 项工具的排名。

从能调用，到能稳定交付

01
先完成精选方案

普通日常任务先用上方四件套；uv 与 Python 是 MarkItDown 的运行依赖。Node.js、Git、ripgrep、jq 适合开发任务，需要时再装。

02
选择最直接的接口

Agent 能运行命令，就可调用 CLI；能写脚本，就可用 Python 库。需要跨客户端发现工具时，再接 MCP。安装软件本身不会自动把它注册给 Agent。

03
把成功步骤固化

记录可执行文件路径、版本、输入输出、超时与错误信息。先跑通一个小样本，再把它写成脚本或工作流，最后决定是否封装 API / MCP。

04
让输出可检查、可恢复

为每次任务保留原文件、日志和结果路径；转写抽样听，文档渲染看，数据做校验。写入、同步、发布等操作应有明确边界。

按电脑能力选择起点

普通 CPU 电脑优先 CLI、文档转换、SQLite、DuckDB、脚本和浏览器自动化。大文件仍会增加内存需求。
无独显 / 轻薄本可以尝试小模型语音识别与本地 TTS；先用一分钟素材测速度，不把“能运行”等同“实时”。
有 GPU 的电脑再探索 ComfyUI、本地语言模型和较大语音模型。兼容性看 CUDA、Metal 或其他后端，不只看显存数字。
重型生成任务模型大小、量化、分辨率与上下文共同决定资源消耗。先查具体模型说明，再决定升级硬件。

以上为选择建议，不是官方最低配置。目录中的“轻量 / 中等 / 模型相关”是相对部署与资源负担，不是性能基准。

本地工具 + 云端 Agent：工具可能在电脑上执行，但被送给模型的文本与图片仍可能离开本机。要完整离线，模型、工具、依赖和数据源都要满足条件。
