这份清单如何收录

查阅日期：2026 年 11 月 27 日。收录标准：个人电脑可部署、能力边界清晰、存在可脚本化或 Agent 可连接的接口；以项目官方仓库与官方文档为主要来源。

“近期热门”按 GitHub 收藏数与最近创建时间筛选，反映社区关注度，不代表质量排名或长期维护承诺。条目中的应用任务与组合属于编辑建议，未在你的电脑上逐一安装实测，也不是穷尽清单。

系统标签描述通用部署方向，不保证每个硬件、模型或扩展都兼容。Windows 中的 WSL / Docker 路径会在条目内说明。“本地优先”允许首次下载，联网抓取、云盘与远程模型等功能仍需网络。

同名项目容易混淆：本清单中的 VoiceStudio 指 debpalash/VoiceStudio；REA 指 morluto/rea。本项目不隶属于所列工具的维护方，收录不代表授权转售或对兼容性的保证；软件许可与模型许可应分别查阅。

挑选时看什么

01
先看接口

Agent 能运行命令就可调用 CLI；能写脚本就可用 Python 库；需要跨客户端发现工具时再接 MCP。

02
再看门槛

“轻量 / 中等 / 模型相关”是相对部署负担。模型相关工具要额外考虑显存、内存与下载体积。

03
然后看许可

开源不等于无限制免费。软件许可、模型许可与服务条款应分别查阅，以官方页面为准。

04
最后看输出

保留原文件、日志与结果路径。转写抽样听，文档渲染看，数据做校验，写入与发布设边界。
